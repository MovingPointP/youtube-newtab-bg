# 手で確認すること

自動テスト（`npm test`）では確認できないことのチェックリスト。リリースの前などに、普段使っている Chrome で確認する。

自動テストは、Playwright の Chromium（ヘッドレス、YouTube 未ログイン）で動かしているため、次のことは確認できない。

## 音

- [ ] スピーカーを押すと、実際に音が出る・消える
- [ ] 音量スライダーで、実際の音の大きさが変わる

## 実際のブラウザでの動き

- [ ] 別のタブに切り替えると音が止まり、戻ると続きから流れる（自動テストでは `document.hidden` を差し替えて確認している）
- [ ] ウィンドウを最小化しても止まり、戻すと再開する
- [ ] 新しいタブを 2 つ開いて行き来すると、表示している方だけが流れる

## プレイリスト

- [ ] 再生できない動画（埋め込み禁止・非公開・削除済み）を含むプレイリストで、その動画が飛ばされる

## ログイン・CM

- [ ] YouTube にログインした状態で、問題なく再生される
- [ ] CM が流れない（流れたら DESIGN.md 1-4 を見直す）

## 見た目

- [ ] ぼかしと暗さの強さが、背景として自然に見える
- [ ] 長い動画名のスクロールの速さが、読みやすい
